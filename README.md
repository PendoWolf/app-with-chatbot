# Clearlist

A minimal todo app: add tasks, check them off, filter by status, and clear what’s done. Tasks persist in `localStorage`.

## Stack

- React 19
- Vite 8
- Oxlint

## Getting started

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start the dev server     |
| `npm run build`   | Production build         |
| `npm run preview` | Preview the production build |
| `npm run lint`    | Run Oxlint               |
